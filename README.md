# 🍳 Les recettes de Luna — Carnet de cuisine interactif

Une application web interactive, fluide et chaleureuse inspirée d'un carnet de recettes illustré.

## ✨ Fonctionnalités

- 📖 **22 recettes faites maison** : Avec illustrations personnalisées, fiches détaillées, temps de préparation & de cuisson.
- 🔍 **Recherche instantanée** : Filtre en direct par nom de recette, tags ou ingrédients.
- 🏷️ **Filtres par catégories & difficultés** : Plats chauds, Pâtes & Riz, Fromage, Salades, Street food, Végétarien, Soupes.
- 🧊 **Mode Frigo anti-gaspillage** : Sélectionne les ingrédients que tu as sous la main pour trouver quoi cuisiner.
- 👥 **Calculateur de portions intelligent** : Ajuste les quantités d'ingrédients automatiquement (½, ×1, ×2, ×4 personnes).
- ⏱️ **Mode Cuisine immersif & Minuteur** : Parcours pas-à-pas avec raccourcis clavier, validation des étapes, minuteur intégré et célébration confetti.
- ❤️ **Sauvegarde des favoris** : Persistance locale (LocalStorage).

## 🚀 Démarrage rapide

```bash
# Installation des dépendances
npm install

# Lancer en développement
npm run dev

# Construire pour la production
npm run build
```

## 🛠️ Technologies

- **React 19** + **Vite**
- **Lucide React** (Icônes)
- **Canvas-Confetti** (Animations)
- **CSS3 moderne** (Variables, Grid, Flexbox, typographie texturée)
